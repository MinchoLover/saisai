# 사이사이 UI 구현 프롬프트

Flutter로 375×812 모바일 화면을 우선하는 관광 경유지 추천 앱을 구현한다. 서비스 이름은 “사이사이”이며, 목적지까지 남은 시간 안에서 잠깐 들를 수 있는 장소와 코스를 추천한다.

- 분위기: 차분하고 신뢰감 있는 도심 여행, 과도한 장식 없이 따뜻한 녹색 포인트
- 디자인 토큰: primary `#087A5B`, ink `#17221E`, canvas `#F6F8F7`, line `#E2E8E5`, 8pt spacing
- UI 언어: 16~24px radius의 카드, 넉넉한 여백, 명확한 굵기 대비, 하단 고정 CTA, 선택 상태가 즉시 보이는 chip/segmented control
- 접근성: 44px 이상 터치 영역, 충분한 색 대비, 긴 한국어 문구에서 overflow 금지
- 지도: API 키 없는 프로토타입이므로 CustomPainter로 도로·공원·경로·마커를 표현한다. 회색 placeholder처럼 보이지 않게 한다.
- 흐름: 출발/도착 입력 → 남은 시간/이동수단/취향 → 지도 후보 목록 → 장소 상세 → 코스 확정 → 코스 진행 → 마이/경로 기록
- 데이터: mock repository를 사용하되 시간 제약 필터는 실제 동작해야 한다. 체류시간+우회시간이 남은 시간보다 큰 장소는 제외한다.
- 상태: 입력 미완료 버튼 비활성화, 선택 chip 강조, 빈 결과 안내, 뒤로가기 및 하단 내비게이션 동작
- 검증: iPhone 16 Pro 시뮬레이터에서 overflow 없이 Golden Path가 끝까지 동작하고 `flutter analyze`, `flutter test`를 통과해야 한다.
